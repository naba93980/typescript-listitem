## TypeScript List Item

A basic TypeScript project built to practice TypeScript fundamentals through a small list-based application.

### About

This project explores organizing TypeScript code into separate files for list data, individual list items, and rendering templates. It also includes a stylesheet for the application's presentation.


### Concepts Explored

- **TypeScript Fundamentals** — writing TypeScript code in a frontend project
- **Code Organization** — separating application logic into multiple modules
- **View Models** — organizing list-related logic using `FullList.ts` and `ListItem.ts`
- **Templates** — handling list presentation through `ListTemplate.ts`
- **Application Entry Point** — using `main.ts` to bring the application code together
- **TypeScript Configuration** — configuring the compiler through `tsconfig.json`
- **CSS Styling** — styling the application using a separate stylesheet



### Getting Started

Clone the repository:

```bash
git clone https://github.com/naba93980/typescript-listitem.git
cd typescript-listitem
```

Install the project dependencies:

```bash
npm install
```

Start the development server using the script configured in `package.json`:

```bash
npm run dev
```

### Purpose

This project is a hands-on exercise in building a small frontend application with TypeScript while practicing modular code organization and separating list logic from presentation.
